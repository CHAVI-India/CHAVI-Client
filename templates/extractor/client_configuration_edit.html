Text deidentification (local LLM NER)

Model role: a System-2 (autoregressive) model can be selected as the NER engine inside a deidentification pipeline, running alongside the rule-based recognizers. A System-1 (decision) model judges candidate spans and may run locally or on a remote endpoint. A System-2 model used for text deidentification must run on this machine or the local network — deidentified clinical text never leaves the local network; cloud providers are rejected for that role.

The deidentification default is set on a deidentification pipeline, not here.

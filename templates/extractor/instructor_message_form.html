About Instructor Messages

Messages follow the standard LLM format: {"role": "system/user", "content": "your text"}

  • System messages provide instructions and context to guide the LLM
  • User messages are automatically generated with:
    • Field schema from your ResponseModel configuration
    • The document content to extract from
  • Messages are sent to the LLM in creation order
  • Multiple system messages can be used to build complex instructions
  • Clear, specific instructions produce better extraction results

Example System Prompts (Instructor Format)

Medical Data Extraction (System Role) 

You are a medical data extraction assistant. Extract structured information from medical documents with high accuracy.

Instructions:
- Extract ONLY information explicitly stated in the document
- Use standard medical terminology and codes
- If information is unclear or missing, set the field to null/empty
- Pay careful attention to dates (use YYYY-MM-DD format), measurements, and medical codes
- Maintain patient confidentiality and data integrity
- Do not infer, assume, or hallucinate missing information

The document content will be provided in the next message.

Structured Data Extraction (System Role) 

Extract structured data from the provided document according to the defined schema.

Requirements:
- Use exact values as they appear in the document
- Convert dates to YYYY-MM-DD format
- Extract numerical values without units (units are defined in the schema)
- Maintain data integrity and accuracy
- Leave fields empty if information is not present
- Do not infer or assume missing information
- Follow the Pydantic model schema exactly

The user message will contain the document to extract from.

Multi-Step Instructions (System Role) 

You are extracting patient diagnosis information from medical records.

Step-by-step process:
1. Identify the patient demographics section
2. Locate all diagnosis entries with their ICD codes
3. Extract diagnosis dates and descriptions
4. Identify the treating physician
5. Extract any follow-up information

Quality checks:
- Verify all dates are in YYYY-MM-DD format
- Ensure ICD codes are complete and valid
- Cross-reference patient ID across sections
- Flag any inconsistencies in the notes field

Note: The actual document content is automatically added as a user message when extraction runs. You only need to configure the system instructions here.

How Messages Are Sent to Instructor 

client.chat.completions.create(
    model="your-model",
    response_model=YourPydanticModel,
    messages=[
        {
            "role": "system",
            "content": "Your system prompt text here..."
        },
        {
            "role": "user", 
            "content": """Extract the following fields:
            
DIAGNOSIS Fields:
  - diagnosis_code (string)
  - diagnosis_date (date)
  - diagnosis_description (string)
  
Document content:
[Your uploaded document text]"""
        }
    ]
)

The field schema and document content are automatically generated from your ResponseModel configuration. You only need to write the system instructions.

{% component "form_field" label="Similarity Threshold" field_id="similarity_threshold" extra_class="mb-4" %}

Minimum cosine similarity (0–1) for a semantic match to be accepted as the final label. Higher = stricter matching; 0.7 is a typical starting point.

{% endcomponent %} {% component "form_field" label="Candidate Threshold" field_id="candidate_threshold" extra_class="mb-4" %}

Looser cutoff used when collecting candidate options to show the LLM — should be below the similarity threshold (lower = more candidates, more LLM tokens).

{% endcomponent %} {% component "form_field" label="Top K Results" field_id="top_k_results" extra_class="mb-4" %}

How many of the closest lookup entries are offered to the LLM as candidate matches.

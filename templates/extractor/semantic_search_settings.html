How Semantic Search Works

1. Configuration: Set up an embedding model (e.g., all-MiniLM-L6-v2) to convert text into vectors.

2. Pre-computation: All lookup table entries are converted to embeddings and stored.

3. During Extraction: Document text is embedded and compared to lookup embeddings to find the most similar matches.

4. LLM Receives: Only the top-K most relevant options, improving accuracy and reducing token usage.

How to Map Fields

Connect your CSV columns to the database fields where the data should be stored. You can map multiple CSV columns to a single field for wide-format data.

Examples:

  • Simple mapping: CSV column "PatientID" → Patient.patient_id field
  • Wide format: CSV columns "Diabetes", "Hypertension", "Asthma" → Comorbidity.comorbidity_type field (creates 3 separate records)
  • Date mapping: CSV column "DOB" → Patient.date_of_birth field

💡 Tip: Use Ctrl+Click (or Cmd+Click on Mac) to select multiple columns

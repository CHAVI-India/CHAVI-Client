Column Name as Data (Wide Format)

This step handles "wide format" data where the column name itself represents a value, not just a label. The column contains presence/absence or other indicators.

Example - Comorbidities in Wide Format:

CSV: PatientID | Diabetes | Hypertension | Asthma

P001 | Yes | No | Yes

Mapping:

  • Column "Diabetes" → Field: Comorbidity.comorbidity_type, Value: "Diabetes"
  • Column "Hypertension" → Field: Comorbidity.comorbidity_type, Value: "Hypertension"
  • Column "Asthma" → Field: Comorbidity.comorbidity_type, Value: "Asthma"

💡 Result: Creates 2 Comorbidity records for P001 (Diabetes and Asthma)

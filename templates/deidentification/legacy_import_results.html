How to resolve unmatched records:

  1. Click Create All Missing Records above to dispatch a background task that creates every unmatched record. You will be redirected to the task list to monitor progress.
  2. Alternatively, expand a patient row to create records individually or per-patient.
  3. For Series, the parent Study UID is pre-filled from the hierarchy. For Instances, the parent Series UID is pre-filled.
  4. After creating all missing records, click Re-upload Legacy Files below to re-run the import and link deidentified mappings.

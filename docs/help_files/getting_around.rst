Finding Your Way Around
==========================

This page covers the everyday screens that help you find things and keep track of what the system is doing.

Home
-----

The home page shows a summary of the data in the system — how many patients, studies and records there are — with shortcuts to the main tasks.

Patient Search
---------------

Click **Patient Search** in the top menu to look up a patient. Type part of the patient ID to search, then click **View Summary** to open the patient's summary page, which shows everything recorded for them.

Task Runs
----------

Big jobs — imports, fetches, de-identification — run in the background. Click **Task Runs** in the top menu to see them all.

Each job shows what it is, who started it, and its status:

* **Pending / Started / In Progress** — still working
* **Success** — finished
* **Failure** — stopped with an error
* **Stalled** — stopped making progress

Open a job to see its details and any error messages. If a job failed or stalled, you can usually start it again with the **Retry** or **Resume** button on that page — it will pick up where it left off rather than starting over.

Notifications
--------------

The bell icon at the top right shows a count of unread messages. Click it to see recent notifications — mostly about background jobs finishing — and click a message to go to the related page.

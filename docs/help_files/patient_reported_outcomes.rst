Patient Reported Outcomes
======================

The Patient Reported Outcomes (PRO) module captures patient-perspective data using standardized assessment tools.

Data Collection Fields
--------------------

Instrument Information
^^^^^^^^^^^^^^^^^^
* **Patient Link**: The patient completing the assessment
* **PRO Instrument**: Standardized questionnaire used
* **Domain**: Specific area being assessed
* **Question**: Individual item from the instrument

Response Data
^^^^^^^^^^
* **Assessment Date**: When the PRO was completed
* **Answer**: Patient's response to the question
* **Score**: Numerical value if applicable

Special Considerations
--------------------

1. Data Collection:

   #. Use validated instruments  
   #. Record complete responses  
   #. Note missing data  

2. Timing:

   #. Follow assessment schedule  
   #. Document completion dates  
   #. Track longitudinal changes

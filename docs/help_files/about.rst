About
======

The CHAVI client is a Django application that is designed to allow users to manage the data for the `CHAVI project <https://chavi.ai>`__. This allows the users to add, edit, and review the clinical data related to the patient before the data is ready for uploading to the CHAVI database. The application allows the users to add, edit, and review the following data:

    - :doc:`Patient Demographics <patient_demographics>`
        - :doc:`Diagnosis data <diagnosis>`
            - :doc:`Lesion <lesion>`
                - :doc:`Lesion Response <lesion_response>`
            - :doc:`Pathology data <pathology>`
                - :doc:`Immunohistochemistry <immunohistochemistry>`
                - :doc:`Cytogenetics <cytogenetics>`
                - :doc:`Somatic Genomic Alterations <somatic_genomic_alterations>`
                - :doc:`Epigenetic Modifications <epigenetic_modifications>`
                - :doc:`Gene Expression Data <gene_expression_data>`
            - :doc:`Systemic therapy <systemic_therapy>`
                - :doc:`Systemic Therapy Drug Schedule <systemic_therapy_drug_schedule>`
            - :doc:`Radiation therapy <radiation_therapy>`

            - :doc:`Surgery <surgery>`

Cytogenetics
===========

The Cytogenetics module captures information about genetic alterations detected through cytogenetic testing. This includes chromosomal abnormalities and gene rearrangements that may influence diagnosis, prognosis, and treatment decisions.

Data Collection Fields
--------------------

Test Information
^^^^^^^^^^^^^
* **Pathology Link**: The pathology report this cytogenetic testing is associated with
* **Date of Test**: When the cytogenetic testing was performed
* **Gene**: The specific gene tested (from standardized gene list)

Results
^^^^^^
* **Cytogenetic Result**: Overall result of testing (Positive/Negative/Not Evaluable)

Special Considerations
--------------------

1. Gene Selection:

   #. Choose from standardized gene list  
   #. Ensure correct gene symbol is used  
   #. Record each gene test separately  

2. Result Documentation:

   #. Record results consistently  
   #. Note any technical limitations  
   #. Document quality of testing  

3. Multiple Tests:

   #. Create separate entries for each gene tested  
   #. Maintain chronological order of testing  
   #. Link to appropriate pathology reports

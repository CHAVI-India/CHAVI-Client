Suggested Data Entry Workflow
===============================

We suggest that you use the following workflow when entring patient data.

#. First enter the patient data. A basic set of clinical data especially the patient ID is required. 
#. After completing clinical data entry, then upload the DICOM data for the given patient. 
#. Process the DICOM data.
#. Associate the patient and DICOM data to the project.
#. Ensure that the DICOM study types are properly assigned. 
#. Finally associate the DICOM studies to specific diagnoses / treatments as required.

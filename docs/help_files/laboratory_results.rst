Laboratory Results
================

The Laboratory Results module tracks various clinical laboratory test results for patients throughout their treatment course.

Data Collection Fields
--------------------

Test Information
^^^^^^^^^^^^^
* **Patient Link**: The patient these results belong to
* **Laboratory Test**: Type of test performed (from standardized list)
* **Result Date**: When the test was performed

Result Details
^^^^^^^^^^^
* **Result Value**: Numerical test result
* **Result Unit**: Units of measurement

Special Considerations
--------------------

1. Data Entry:

   #. Use consistent units  
   #. Record dates accurately  
   #. Note any abnormal values  

2. Timeline:

   #. Track changes over time  
   #. Document clinically relevant tests

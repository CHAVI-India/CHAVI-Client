Surgery
=======

The Surgery module captures information about surgical procedures performed as part of cancer treatment.

Data Collection Fields
--------------------

Basic Information
^^^^^^^^^^^^^^^
* **Diagnosis Link**: The diagnosis this surgery is associated with
* **Surgery Date**: When the procedure was performed
* **Surgery Side**: Laterality of the procedure
* **Surgery Type**: Type of surgical procedure performed

Lymph Node Assessment
^^^^^^^^^^^^^^^^^
* **Nodal Assessment**: Whether lymph nodes were evaluated
* **Assessment Type**: Method of node evaluation (e.g., Sentinel Node, Axillary Dissection)

Reconstruction
^^^^^^^^^^^^
* **Reconstruction Performed**: Whether reconstruction was done
* **Reconstruction Type**: Type of reconstructive procedure

Documentation
^^^^^^^^^^^
* **Associated DICOM Studies**: Imaging studies related to surgery

Special Considerations
--------------------

1. Procedure Details:

   #. Document complete surgical procedure  
   #. Note any complications  
   #. Record reconstruction details  

2. Timing Documentation:

   #. Record surgery date accurately  
   #. Note sequence relative to other treatments

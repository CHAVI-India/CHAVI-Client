Concomitant Medications
=====================

The Concomitant Medications module tracks medications given alongside primary cancer treatments.

Data Collection Fields
--------------------

Medication Information
^^^^^^^^^^^^^^^^^^
* **Diagnosis Link**: Associated diagnosis
* **Medication Name**: Name of the medication
* **Medication Dose**: Amount prescribed
* **Dose Units**: Units of measurement

Administration Details
^^^^^^^^^^^^^^^^^^
* **Start Date**: When medication was started
* **End Date**: When medication was stopped
* **Route**: How medication is given

--------------------
